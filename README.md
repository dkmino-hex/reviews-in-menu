## Что за сервис

Review Breaker («Разбивака») — веб-приложение для ресторана, которое объединяет электронное меню и обратную связь от посетителей. Цель проекта — помочь ресторану понять, какие блюда нравятся гостям и что стоит улучшить, на основе оценок и текстовых отзывов.

## Технологии

React и TypeScript для интерфейса, Go для API, PostgreSQL для хранения данных. Приложение запускается через Docker Compose.
